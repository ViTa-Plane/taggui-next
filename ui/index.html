Help & Keyboard Shortcuts

Navigation & Selection
  • Arrow Keys: Navigate through images in the grid
  • Shift + Click: Multi-select range of images or add tag to selection
  • Ctrl / Cmd + Click: Toggle individual image selection or add tag to keywords
  • Ctrl / Cmd + A: Select all filtered images
  • Escape: Clear selections or active filters
Tag Editing & Management
  • Double-Click Tag: Rename tag globally or edit individual tag
  • Drag & Drop Tags: Reorder tags on the selected image
  • Ctrl / Cmd + Z: Undo last change
  • Ctrl / Cmd + Shift + Z: Redo last change
  • Delete / Backspace: Delete selected tag globally (when tag is focused)
Local AutoTagging

Click ✨ AutoTag to analyze images locally using your selected model. Configure models, confidence thresholds, and strategies via the ⚙️ Settings button.
